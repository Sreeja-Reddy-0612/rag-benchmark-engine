# RAG Benchmark Engine

An evaluation-first Retrieval-Augmented Generation (RAG) benchmarking system designed to
measure retrieval quality, answer faithfulness, hallucination rate, and cost across multiple
RAG pipeline architectures.

## Project Status

- [x] Step 1: Document ingestion and normalization
- [x] Step 2: Chunking engine (fixed and recursive strategies)
- [x] Step 3: Embeddings and FAISS-based vector store
- [x] Step 4: RAG pipelines (basic and reranked)
- [x] Step 5: Evaluation and benchmarking
